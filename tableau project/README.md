# Amazon Sales Performance & Customer Segmentation Dashboard

## Project Overview

This project presents an interactive Tableau dashboard for analyzing sales performance, profitability, discount impact, regional sales, and customer purchasing behaviour.

The project combines two practicals:

- Practical 13: Retail Sales & Profitability Dashboard
- Practical 14: Customer Segmentation & Behavior Analysis

## Objectives

- Analyze total sales and profit.
- Compare sales and profit across product categories.
- Analyze regional and state-wise sales performance.
- Study the impact of discounts on profit.
- Identify top-performing products.
- Analyze customer Recency, Frequency and Monetary Value.
- Segment customers using Tableau clustering.
- Identify high-value customers.

## Dataset

The project uses an Amazon-style retail sales dataset containing order, customer, product, regional, sales, discount and profit information.

### Main Fields

- Order ID
- Order Date
- Customer ID
- Region
- State
- City
- Category
- Product Name
- Quantity
- Actual Price
- Discount Percentage
- Sales
- Profit
- Profit Ratio

## Tools Used

- Tableau Desktop
- CSV Dataset
- Tableau Calculated Fields
- Tableau Maps
- Tableau Clustering

## Dashboard Components

- Total Sales
- Total Profit
- Total Quantity
- Profit Ratio
- Sales Trend
- Sales by Category
- Profit by Category
- Sales by Region
- Regional/State Map
- Discount vs Profit
- Top 10 Products
- Customer RFM Analysis
- Customer Segmentation
- High-Value Customers

## Customer Segmentation

Customer behaviour is analyzed using:

- Recency
- Frequency
- Monetary Value

Tableau clustering is used to group customers based on their purchasing behaviour.

## Project Files

The repository contains the Tableau workbook, dataset, project report and dashboard screenshots.

## Conclusion

The dashboard provides a simple and interactive way to understand sales performance and customer purchasing behaviour. It helps identify important categories, regions, products and customer segments that can support better business decisions.
